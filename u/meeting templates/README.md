# Шаблоны протоколов встреч

Набор переиспользуемых блоков и надстроек под типы созвонов для создания структурированных транскрипт-отчётов.

## Структура

### Ядро (базовые блоки)
- `0_core_block_a_prompt.md` — Универсальный промпт-инструкция
- `0_core_block_b_template.md` — Универсальный шаблон структуры вывода
- `0_core_block_c_input_format.md` — Формат входных данных

### Шаблоны по типам встреч
- `1_consultation.md` — Консультации
- `2_book_team_meeting.md` — Оргвстречи команды по написанию книги
- `3_marketing_meeting.md` — Оргвстречи с маркетологом
- `4_software_development_client.md` — Встречи с заказчиками по разработке ПО
- `5_custdev.md` — Customer Development встречи
- `6_dev_experience_sharing.md` — Встречи с коллегами по разработке (обмен опытом)
- `7_general_meeting.md` — Общие встречи (универсальный)

## Как пользоваться

1. Возьмите **Блок A** (промпт-инструкция)
2. Добавьте **надстройку нужного типа** (1–7)
3. Используйте **Блок B** как структуру вывода
4. Вставьте транскрипт в формате **Блока C**

## Мини-режим

Если нужен очень короткий результат, добавьте в конец промпта:

```
РЕЖИМ MINI:
- Лог разговора сократи до 7–12 буллетов.
- Цитаты — максимум 3.
- Решения и действия — обязательно.
```
